# 7주차 리더보드 v2 제출

202312312 송명진 · 정책 v2

제출 모델: [my_policy_v2.onnx](my_policy_v2.onnx). 입력 `image`: float32 `(N, 3, 66, 200)`, 0~1. 출력 `steer`: float32 `(N, 1)`.

기존 Drive의 `week05/my_dataset_v1.npz` 2,848프레임과 `week06/my_policy_v1.pt`를 불러와 DAgger 2회전을 실행했습니다. 회전마다 공개 A·B·C에서 각 400프레임을 수집하고, 새 데이터만 리밸런스한 뒤 집계했습니다. 현재 정책에서 3에폭, 학습률 3e-4로 재학습했고, 공개 1.2× 점수가 가장 높은 **v1**를 제출 모델로 선택했습니다. 학습·선택 프로토콜은 배포 노트북을 따릅니다.

이번 실행에서는 강화 외란 성능이 개선되지 않았습니다. 시드 0의 공개 1.2× 점수는 v1 69.9 → D1 21.9 → D2 22.0이어서, 최종 제출 모델은 기존 v1 가중치를 v2 형식으로 내보낸 것입니다. 학습 결과와 성능 하락을 그대로 기록했습니다.

아래는 **제출 ONNX 자체**를 시드 0·1·2로 평가한 평균 점수입니다. v1도 기존 제출 ONNX를 같은 조건으로 평가했습니다. 외란 주기는 50스텝이며 1.0×는 d=0.35, ψ=0.3, 1.2×는 d=0.42, ψ=0.36입니다. 이미지 노이즈 0.02, 에피소드당 최대 1,500스텝을 사용했습니다.

| 정책 / 트랙 | 외란 1.0× | 외란 1.2× |
| --- | ---: | ---: |
| v1 / 공개 A·B·C | 86.43 | 69.58 |
| v2 / 공개 A·B·C | 86.43 | 69.58 |
| Δ(v2−v1) / 공개 A·B·C | +0.00 | +0.00 |
| v1 / 노트북 랜덤 101·202 | 86.62 | 62.72 |
| v2 / 노트북 랜덤 101·202 | 86.62 | 62.72 |
| Δ(v2−v1) / 노트북 랜덤 101·202 | +0.00 | +0.00 |

랜덤 101·202 트랙은 배포 노트북에 공개된 시드로 생성한 자체 평가입니다. 강사의 미공개 채점 결과가 아닙니다.

ONNX 검사와 배치 1·8의 PyTorch 비교를 통과했습니다. 최대 절대 출력 차이는 1.19e-07이며, 허용 기준은 1e-4입니다.
