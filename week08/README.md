`Week08_demo.ipynb`의 준비부터 종합표 생성까지 모두 실행했습니다. 기존 7주차 `my_policy_v2.pt`와 `my_dataset_v2.npz` 4,421프레임을 사용했고, run 단위로 학습 3,278 / 검증 1,143프레임을 분리했습니다. `FAST=False`로 멀티태스크 λ=0·0.1·0.5·1.0, 시간 정보, 명령 조건부 실험을 모두 실행했습니다. 멀티태스크·시간 정보는 배포본의 3,000프레임·2에폭 설정을 사용합니다.

조건별 비교는 시드 0, 공개 A/B/C에서 트랙당 1에피소드·최대 1,500스텝, 기본 이미지 노이즈 0.02를 사용합니다. 외란 주기는 50스텝이며 기본 d=0.35 m·ψ=0.3 rad, 1.2×는 d=0.42 m·ψ=0.36 rad입니다. 노이즈 조건은 0.08이며 스타일 조건은 배포본의 어두운 노면·차선 색을 적용했습니다. 멀티태스크·프레임 스택의 종합표 점수는 기본 조건만 평가했습니다.

‘미공개’는 배포 노트북에 제공된 시드 101·202의 랜덤 트랙 자체 평가입니다. 교수님의 비공개 채점 결과가 아니며, 모든 결과는 이번 단일 시드 실험 범위에서 해석했습니다. 멀티태스크의 폐루프 평가는 조향 헤드만 사용하므로 실제 차량 속도를 제어한 결과가 아닙니다.

로컬 실행을 위해 입출력 경로, Windows 한글 글꼴, CPU 2스레드, 전체 모드, 그래프의 축 이름·점수 단위를 설정했습니다. 정책 구조·학습률·에폭·평가 조건은 배포본을 따릅니다. `AIAPP_ROOT`는 week07 폴더가 들어 있는 상위 폴더, `WEEK08_SAVE_DIR`는 결과 폴더로 지정할 수 있습니다. 이 환경 변수가 없으면 배포본의 Colab/로컬 경로를 사용합니다. 실행에는 제공된 `tinytrack.py`가 필요합니다.

제출용 조건별 그래프는 동일한 `compare_v2.csv`의 수치로 다시 그려 점수 라벨을 추가하고 범례가 작은 막대를 가리지 않도록 배치했습니다.

비교 정책 `ModularPolicy`와 `TorchPolicy`는 `state` 인수를 사용하지 않고 영상으로만 조향을 결정합니다. 렌더 보정·속도 라벨·전문가 데이터 생성에서 상태를 사용하는 부분은 배포 실험의 일부입니다. 강의자료 19쪽과 비교한 예상 차이는 E2E의 스타일 성능 유지와 모듈형의 강한 외란 성능 하락입니다.

데이터셋·학습 체크포인트는 업로드에서 제외했습니다. 점수표와 리포트 수치, 멀티태스크·시간 정보의 기본 점수, 노트북 전체 실행 및 오류 부재, 그래프 파일을 검증했습니다.
